# MITS-Altair-8800-Sample-Code
Some simple 8080 bare-metal assembly code for the Altair 8800.
All programs are designed to work with the MITS Altair Programming
System II and may not work with other assemblers.
- cylon.asm is a version of Gwen Nelson's cylon program adapted for the MITS Altair Programming System II. It displays on the leftmost half of the memory bus LEDs a Cylon-like sweeping effect. Inspired by kill-the-bit and Battlestar Galactica.
- hello.asm is a hello world program
